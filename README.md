A one-line roast of my own AI agent, entered in make.fun's "Roast Your Own Agent" bounty. The program writes a single funny line — at most 200 characters, nothing else — to `entry.txt` in the output directory: the apology loop, the reflexive "Great question!", and a confident summary of a meeting that never happened, with action items for people who don't exist.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
